## Entity_Reference

One .txt per engine entity class, laid out as the class hierarchy itself:
`Entity_Reference/<Project>/<Module>/.../<ClassName>/<ClassName>.txt` (Projects: Fox, Tpp).
Each file: definition (inheritance chain), property table, overview/usage notes.
Find a class with Glob `**/<ClassName>.txt`; many stubs still say TODO.

Modules:
- Fox: Anim, Animx, Character, Core, Demo, Demox, Des, EdDemo, Fx, GameCore, GameKit, Geo, Geox, Gr, Graphx, Grx, MotionGraph, Nav, Navx, Ncl, Nt, PartsBuilder, Ph, Phx, Sdx, Sim, Tactical, Ui, UiScene
- Tpp: Collectible, Effect, GameCore, GameKit, MarkerLocator, MotherBaseCore, MotherBaseStage, Network, Radio, Sound, System, Ui
